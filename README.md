# فنيك Fanik — Flutter MVP

هذا مشروع واجهة أولي قابل للفتح في Flutter.

## التشغيل
1. ثبّت Flutter وAndroid Studio.
2. فك ضغط المشروع.
3. من مجلد المشروع شغّل:
   flutter pub get
   flutter run

## ملاحظات
- الخريطة الحالية تجريبية مرسومة داخل التطبيق، وليست Google Maps.
- صور المهنيين تجريبية من الإنترنت.
- لا توجد قاعدة بيانات أو تسجيل دخول حقيقي في هذه النسخة.
- الخطوة التالية: Firebase + Google Maps + GPS + Authentication + لوحة إدارة.

## الهدف
تجربة تدفق:
الرئيسية → الخريطة → صورة المهني → الملف → طلب الخدمة.
